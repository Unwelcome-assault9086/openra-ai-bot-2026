## 🛠️ Troubleshooting

If something isn't working, try these common fixes:

**Problem: The AI doesn't seem different**
- Make sure you copied the files to the correct OpenRA folder
- Restart OpenRA completely after installation
- Check that you selected "Computer" as the opponent, not a scripted bot

**Problem: OpenRA won't start**
- Verify you extracted the ZIP file completely
- Ensure you didn't delete any original OpenRA files
- Try reinstalling OpenRA, then add the AI bot again

**Problem: Game crashes during matches**
- Update your graphics drivers
- Close other programs that use lots of memory
- Reduce graphics quality in OpenRA settings

**Problem: Can't find the OpenRA folder**
- Use the search function in Windows Explorer
- Look in both `Documents` and `AppData` locations
- Check if OpenRA is installed in `Program Files`
